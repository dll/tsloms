### 2.3 已实现但存在缺陷 ⚠️

| 缺陷 | 影响 |
|------|------|
| **故障时间筛选参数不匹配**：前端 `fault` 页发送 `start_date`/`end_date`，后端 `ListFaults` 读取 `start_time`/`end_time` → 故障时间筛选**静默失效** | 功能缺陷 |
| **工单「已驳回」状态被立即改写**：`UpdateWorkOrderStatus` 收到 `rejected` 后将其改回 `pending`，导致工单**永远不会处于 rejected**，前端"已驳回"标签永远不显示 | 与 PRD 状态机及前端 UI 不一致 |
| **工单编号生成**：`WO{yyyyMMdd}{seq}` 中 `seq` 直接用 `fault.ID%10000`，同日多单可能冲突/不连续，无自增序号 | 数据正确性风险 |

## 三、功能可靠性审核

### 3.1 协议解析（✅ 严谨）

- token、ver、checksum、datLen 多重校验；`datLen` 与实际负载一致性校验防越界；事件记录数×24 长度校验防解析越界（有 panic recover 兜底）。**质量良好。**

### 3.2 并发与消息处理

- **风险点**：MQTT 回调内**同步**执行数据库写（报文言志、设备 upsert、故障写库、工单创建）。paho 默认单 goroutine 顺序处理消息 → 高并发（百级设备高频签到）下，DB 写延迟会阻塞消息处理，`<100ms` 端到端指标存在风险。建议引入 worker 池 + 异步批量写。

### 3.3 故障研判

- 去重逻辑（同设备同 errCode 30 分钟）正确；超窗将旧故障标 resolved 再建新故障；critical 自动建单。**正确。**

### 3.4 数据库

- GORM AutoMigrate 自动建表，`multiStatements=true`；设备 `hw_id` 唯一索引。但 PRD 结构约定 `migrations/001_init.sql` **不存在**，依赖 AutoMigrate（无版本化 SQL 迁移，生产变更不可控）。

## 四、性能审核

| 项 | 结论 |
|----|------|
| 后端响应延迟 | Gin 高吞吐框架，未压测；需实测 |
| MQTT→故障研判端到端 | 未压测；同步 DB 写是主要瓶颈风险 |
| 报文日志 | 全量同步写 `packet_logs`（含 blob 原始报文），数据量大时膨胀快，PRD 建议**按月分区/归档未实现** |
| 看板趋势查询 | `FaultTrendStats` 全表拉取按 Go 分组，数据量大时内存/IO 开销高；DISTINCT/低基数场景尚可，长期不优 |
| 无缓存 | 统计类查询未用 Redis 缓存 |

**结论**：小规模（百级设备）可用；若无压测数据，`<100ms` 及高并发指标**未证实**。

## 五、代码质量审核

### 5.1 优点
- 分层清晰（handler/model/mqtt/middleware/config）；命名规范；注释完整（中英结合）。
- 统一响应封装 `{code,msg,data}`，生产环境隐藏内部错误。
- JWT 鉴权强制 HS256、防算法混淆；密码 bcrypt；生产环境拒绝弱密钥启动。
- 优雅停机；MQTT 自动重连；panic recover。

### 5.2 问题
- **零单元测试**（`*_test.go` 无），`InitTestDB` 已备好却未使用。
- `middleware/cors.go` 定义了 `isSameOrigin`/`originHost` 但**未使用**（死代码），且生产未实现白名单。
- `handler/response.go` 有 `HashPassword` 重复实现（`model` 包已有），且 `created`/`forbidden` 等函数**未被使用**。
- `FaultTrendStats` 手写冒泡排序可读性差、可替换为 `sort.Slice`。
- Dockerfile 构建产物将数据库/凭据等未列入 `.dockerignore` 风险（详查 .gitignore）。

## 七、数据安全审核

| 项 | 现状 | 风险 |
|----|------|------|
| 登录鉴权 | ✅ JWT(HS256,72h) + bcrypt | - |
| 权限校验 | ✅ operator/admin 中间件 | - |
| CORS | 🔴 **生产无白名单**，回显任意 Origin、放行 Authorization 头 | 配合已登录 token，可能被恶意站点跨域调用（CSRF 式风险） |
| JWT Secret | ✅ 生产拒绝弱密钥 | - |
| 数据库口令 | ✅ `.env` 分离，未入库 | `.env` 在生产存在 |
| MQTT 认证 | 🟠 生产 `MQTT_USERNAME` 为空（broker 无鉴权） | 弱 |
| 操作审计 | 🔴 无操作日志落库（见 2.2） | 无法溯源 |
| 原始报文 | 落库为明文 blob | 含设备/业务信息，建议接入访问控制 |
| 密钥泄露风险 | `.env.example` 使用占位符，`docker-compose.yml` 用 `***` | 需确认仓库无真实密钥 |
