# TSLOMS 信号灯检测器接入操作（简化版）

> 适用：信号灯运维员 · 生产环境 `http://129.211.223.113:8092/`
> 目标：以 admin 登录，完成检测器接入并验证

## 一、登录系统

1. 浏览器打开 `http://129.211.223.113:8092/tsloms/admin/`
2. 输入账号 `admin` 和密码 Tsloms@2026
3. 填写算术验证码（如 `2+8=?` 填 `10`），点「登录」
4. 登录成功进入仪表盘

## 二、查看检测器接入状态

左侧菜单 →「检测器接入」，确认「真实硬件接入」显示**已连接**。

## 三、配置检测器（需厂商工具 trafficLightConf）

在检测器配置文件 `trafficLight.ini` 中设置：


| 参数                        | 填写值               |
| ------------------------- | ----------------- |
| mqttServerUserIp          | `129.211.223.113` |
| mqttServerPort            | `1883`            |
| mqttUserName              | `det123`（最长 8 位）  |
| mqttPassword              | 检测器账号密码           |
| mqttTopicPrefix           | `trafficLight`    |
| networkCode / stationCode | `0`               |


执行下发：

```bash
./trafficLightConf <硬件ID>
```



## 四、验证接入成功

### 4.1 确认 Broker 连接

1. 左侧菜单 →「检测器接入」
2. 查看「真实硬件接入」卡片，确认显示**已连接**
3. 查看「在线设备」数字，确认有新设备接入后数字增加

### 4.2 确认设备台账

1. 左侧菜单 →「设备管理」
2. 在设备列表中找到该检测器（按硬件 ID 搜索）
3. 确认设备状态为**在线**，硬件 ID、更新时间正确

### 4.3 确认故障记录

1. 左侧菜单 →「故障管理」
2. 查看是否有该设备产生的故障记录（检测器上报 ALARM 后出现）
3. 确认故障类型、等级与错误码一致

### 4.4 确认维修工单

1. 左侧菜单 →「工单管理」
2. 确认存在自动生成的维修工单，关联到对应设备与故障

### 4.5 验证完成标准

- 设备管理：设备在线 ✅
- 故障管理：故障记录存在 ✅
- 工单管理：维修工单已生成 ✅
- 检测器接入页：Broker 已连接、在线设备增长 ✅

> 全部通过即接入成功。若设备不在线，检查检测器网络与账号配置；若接入页显示未连接，联系管理员检查 MQTT 服务。新增检测器账号需联系管理员在 EMQX 创建。
