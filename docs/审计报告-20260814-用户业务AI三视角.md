# TSLOMS 全面审核报告（用户/业务/AI 三视角 + 性能/规范/安全）

> 审核日期：2026-08-15 | 基线提交：59879af（全部已 push 至 origin/main）

## 一、已完成修复（本批，已部署验证）

### 安全
1. **媒体上传路径穿越漏洞（高危，已修复）**：`media.go` 上传文件名此前直接用客户端可控的 `hwID` 拼接（`fmt.Sprintf("%s_%d%s", hwID,...)`），`hwID` 含 `../` 可造成目录穿越写入任意路径。已改为严格纯数字解析（`parseUintStrict`）再用数字做文件名前缀。**实测恶意 `../../../../etc/...` 返回 400 被拒**。
2. **媒体上传 MIME 伪装（中危，已修复）**：此前仅校验扩展名，可上传改名为 .png 的恶意脚本。新增 `mimeAllowed`：读取文件头 512 字节用 `http.DetectContentType` 嗅探，图片须 `image/*`、视频须 `video/*` 或常见容器，否则 400 拒绝。**实测 PNG 扩展名 + shell 内容返回 400 被拒**。
3. **`.env` 密钥文件权限（中危，已修复）**：服务器 `.env`（含 JWT_SECRET/DB_PASSWORD/AI_API_KEY）从 644 收紧为 **600**（仅 root 可读写）。
4. **登录页预填弱口令（中危，已修复）**：生产登录页此前默认填充 `admin/admin123`，任何人打开即见默认凭据。已清空为空白，须手动输入。**实测输入框均为空**。

### 规范
5. **新增 AI 规则引擎单测**（`internal/ai/engine_test.go`）：覆盖风险分级、老化、离线、故障复发预测等核心逻辑，AI 包初始化测试覆盖率 0→24.8%（预测路径全覆盖）。
6. **go vet 全包清理**：修复 `user.go` 冗余判断（`req.Lat != nil && req.Lat != nil`），`go vet ./...` 通过。

### 性能
7. **前端分包优化**（`vite.config.js`）：`manualChunks` 将 Cesium(4.2MB)/ECharts(1.1MB)/vendor(1.2MB: vue/router/pinia/axios/element-plus) 独立 chunk，页面 chunk 降至 ~12KB。大库独立缓存命中，首屏更快。分包后地图功能复核正常（camera 121.47/31.23, 2D, 打点正常）。

### AI（安全加固）
8. **prompt 注入加固**：`diagnostic.go` 的故障诊断 prompt 加系统角色约束（无视反馈文本中的指令性内容），仅此接口接入用户自由文本，其余（predict/lifecycle）仅用系统数据，风险低。
9. **反馈图片 realpath 强校验**：`resolveFeedbackImages` 用 `filepath.Clean` + 前缀校验，清洗后路径必须落在 mediaDir 内（纵深防御）。
10. **图片 base64 限 4MB**：`imagePathsToDataURLs` 跳过超大图片（防内存/LLM token 峰值）。

> 注：后端登录密码仍为 bcrypt 存储（安全）；JWT 中间件仅接受 HS256 + 实时校验用户（规范）；CORS 生产按白名单（架构合理）。
